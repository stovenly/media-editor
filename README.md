# Media Editor

Convert and edit images, audio and video in your browser. Files are processed on
your device and never uploaded.

- Convert between image, audio, video and subtitle formats
- Edit images: crop, rotate, adjust, resize, redact
- Edit audio: cut, join, mix, fade, normalise
- Edit video: trim, join, overlays, music, text, captions, redaction
- Save projects and reopen them later
